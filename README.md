# BWTHW – Erasmhealth Project

A mobile health-tracking app built for the BWTHW (Biomedical Wearable Technologies for Healthcare and Wellbeing) course at Unipd. The app connects to the [IMPACT](https://impact.dei.unipd.it/bwthw/) platform to retrieve wearable health data from a Fitbit, computes a personal wellness score, and helps users understand how lifestyle choices related to alcohol affect their recovery. The application is a proposed solution to the SDG Target 3.5: Strengthen the prevention and treatment of substance abuse, including narcotic drug abuse and harmful use of alcohol.

## Course context

The IMPACT API provides real wearable data (sleep, heart rate, resting heart rate, step count) for a set of test patients. The app reads this data for authorized users, computes a 0–100 wellness score, and presents it in a way that encourages healthy behaviour — particularly around alcohol consumption, sleep, and physical activity.
